Sistema de Control de Rescate y Adopción Animal
Este repositorio contiene el diseño lógico de un sistema para registrar rescates, crear expedientes de animales y asignar voluntarios o veterinarios.

Prototipo HTML
El prototipo del Refugio Huellas Seguras está compuesto por tres páginas interconectadas:

index.html: panel principal con información sobre la capacidad del refugio.
reportar.html: formulario para registrar el ingreso de un animal.
rescates.html: listado de animales alojados y su condición actual.
Organización del proyecto
Los recursos gráficos se encuentran almacenados en la carpeta assets/img. Las páginas comparten una navegación común y utilizan etiquetas semánticas de HTML5.
